# NOVARA – téléchargements

Les versions de **NOVARA**, l'espace de travail pour créer des jeux avec des agents IA (Claude Code,
Codex, Gemini CLI). Ce dépôt ne contient que les fichiers d'installation, pas le code.

**Télécharger** : onglet [Releases](https://github.com/elinahart/novara-releases/releases/latest).

- **macOS** : `NOVARA_<version>_macos.dmg` (Mac Apple ou Intel, macOS 11 ou plus récent).
- **Windows** : bientôt.

Une fois installé, NOVARA se met à jour tout seul : chaque nouvelle version est signée, et sa
signature est vérifiée avant l'installation.

Thèmes et plugins de la communauté : [novara-creations](https://github.com/elinahart/novara-creations).
